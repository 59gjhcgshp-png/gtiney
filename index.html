🔒 Иней — полностью анонимный клиент. Чаты и API-ключи хранятся только в памяти этого браузера (localStorage), запросы уходят напрямую в API выбранного провайдера, минуя любые сервера. У создателя этого приложения нет никакого доступа к вашим ключам, чатам или истории — технически нечего красть. Ключ хранится только в этом браузере (localStorage) и уходит напрямую в API выбранного провайдера. «Скопировать ссылку» кладёт настройки в адрес страницы — можно перенести их на другое устройство. Чаты хранятся локально; «Экспорт» скачает их файлом для переноса. Если Gemini отвечает ошибкой региона (403) — Google не обслуживает запросы из некоторых стран; тогда используй провайдера «Другой» с OpenRouter.
